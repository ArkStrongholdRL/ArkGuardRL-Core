# Rust 环境与特征内核

Rust/PyO3 目前负责：

- 候选路线特征：移动、换位、撤回、旋转射程、支援查询和棋盘汇总在 Rust 中批量计算，
  直接返回 32 列 float32 矩阵。`native/src/route.rs` 每个目录预计算格子和朝向对应的射程，
  每次决策只传棋子与动作的数值索引，不再逐候选构造 Python 单位字典和集合。
- Search parent 的候选关系编码：Python 每个决策复用目录身份和上下文，Rust 一次返回完整矩阵。
- PREP 棋子和道具动作枚举：出售、销毁、移回手牌、部署与换位、装备替换、法术目标，
  保留顺序、容量限制和次数上限后的恢复动作。实现位于 `native/src/prep.rs`。
- 动态观测：实体动态数值、地形与占位、旋转射程覆盖、敌人预览和固定长度打包。
  `native/src/observation.rs` 每个目录保存一份静态射程，直接生成 4784 维观测，
  避免每步复制完整静态实体表再筛选动态列。输入布局和模型权重不变。

保留候选顺序、补偿求和顺序和 float32 配对阈值。输入转成 Rust 自有数值后释放 GIL，
批量特征输出为独立 NumPy 数组，观测输出为不可变数值元组，动作输出为 Python 字典列表。
`env_actions.py` 每个决策整理一次库存、地形及召唤物可部署格子，Rust 批量枚举动作；
`env_observation.py` 复用目录内的 Rust 编码器；Python 整理公开实体引用、全局量和历史反馈。
Python 保留商店/选卡枚举及历史重试过滤。Python/PyTorch 继续负责策略和学习，Node 继续执行游戏。
内部特征读取借用静态目录定义，公开 `record()` 仍返回独立副本。
搜索库存与资产张量只缓存最近一份内容；棋子、商店或资金变化时重新计算。

环境迁移按动作空间、状态与观测、准备阶段状态更新、调度与战斗推进的顺序进行。
当前尚未替换 Node 的游戏状态更新或战斗执行。

```sh
python -m pip install -e '.[vector]'
```

安装时构建 release 扩展，Cargo.lock 固定构建依赖。修改 Rust 后重新安装并重启进程。
加载时只检查扩展接口版本，不扫描源码，也不核对二进制指纹。
