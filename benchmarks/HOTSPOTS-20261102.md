# 环境热点优化（2026-11-02）

当前可运行的 Node 0.3.1 + Rust 动作／观测内核；不是纯 Rust 0.3.3 环境。
优化限于四处：运输层 JSON 状态用 C 编解码复制，保留返回值隔离；
观测检查复用已检查的字段名集合（至多1024个、每名128字符），仍递归检查每个新状态；
候选编码复用决策内手牌槽位数值；Gym 按需获取路线几何，研究接口默认仍随决策返回。

M5／16 GiB，Python 3.12.13、Node 26.7.0、Gymnasium 1.4.0、NumPy 2.5.4。
合法候选均匀随机采样，无模型、训练或轨迹捕获。候选容量16384；Gym seed 42、RNG seed 123。
每环境预热64步、测1024步，每次3遍，按旧／新／新／旧顺序执行，各版本合计6遍。
计入循环内reset，排除初始reset和启动。吞吐为全部真实决策数／墙钟秒。

| 配置 | 旧版中位决策/秒 | 新版中位决策/秒 | 本次变化 |
| --- | ---: | ---: | ---: |
| 单环境 | 480.57 | 494.75 | +2.95% |
| 4环境并行／共享内存 | 899.14 | 937.19 | +4.23% |

桌面负载有波动，这些小幅变化不能证明稳定的训练提速。完整数值见
[测量记录](env-hotspots-20261102.json)。复测命令沿用 `gym_env.py`，加 `--warmup 64 --steps 1024 --repeats 3`。

8项环境测试通过，覆盖按需／默认几何一致、状态隔离、非法动作、候选溢出、自然结束、预算截断和向量reset。
